This project is a Java-based system that includes user registration, login functionality, and a messaging system with validation, hashing, and JSON storage.

Features
- User Registration and Login system
- Message validation (length + recipient format)
- Message hashing system
- JSON message storage simulation
- Unit testing using JUnit
- Git version control with commit history

Testing
JUnit tests were used to validate:
- Message length (success and failure cases)
- Recipient validation
- Message hashing
- Message sending and storing functionality

 Technologies Used
- Java
- JUnit 4/5
- Git & GitHub
